# Search Golf App

条件を指定してゴルフ場を検索する React アプリです。フロントエンドの開発・ビルドには Vite を使用します。

## Requirements

- Node.js 20.19 以上、または 22.12 以上
- npm

## Development

```sh
npm ci
npm start
```

開発サーバーは通常 `http://localhost:5173` で起動します。

## Production build

```sh
npm run build
```

生成物は `dist` ディレクトリに出力されます。ローカルで確認する場合は `npm run preview` を使用します。

## Dependency security

```sh
npm audit
```
